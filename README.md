# Student Information Management System

A console-based **Student Information Management System** developed in C++ to manage and maintain student records efficiently.

## 📌 Project Overview

This project provides a simple interface for managing student information through common record-management operations. It was developed as an academic project to demonstrate fundamental programming concepts, data handling, and CRUD-style operations.

## ✨ Features

* Add new student records
* View student information
* Search for student records
* Update existing student information
* Delete student records
* Manage student-related data through a console interface

## 🛠️ Technologies Used

* **Language:** C++
* **Interface:** Command Line / Console
* **Concepts:** Functions, conditional statements, loops, data structures, file/data handling

## 🚀 Getting Started

### Prerequisites

Install a C++ compiler such as:

* GCC / G++
* MinGW
* Visual Studio
* Code::Blocks

### Run the Project

1. Clone the repository:

```bash
git clone https://github.com/abdaziz77/Student-information-Management-System.git
```

2. Navigate to the project directory:

```bash
cd Student-information-Management-System
```

3. Compile the source file:

```bash
g++ "final project 4.cpp" -o student_management
```

4. Run the program:

```bash
./student_management
```

On Windows:

```bash
student_management.exe
```
